# Character Art Assets

This folder contains the approved character-design references for the power-plant educational game.

## Approved child characters

### Girl Engineer
- Status: Approved
- Canonical filename: `little-engineer-girl-character-sheet.png`
- Approx. age: 8
- Visual style: stylized 3D cartoon
- PPE: white safety helmet, yellow reflective vest, blue workwear, black safety boots
- Helmet emblem: grey + red MAPNA symbol only, no MAPNA text
- Hair: brown, twin ponytails
- Character use:
  - large dialogue portrait / close-up
  - full-body reference
  - small in-game isometric/top-down representation
- Sheet labels: English
- Required views: Front, 3/4 View, Side View, Back
- Required facial expressions: Neutral, Happy, Excited, Thinking, Surprised, Concerned, Confident
- Required action poses: Stand, Point, Explain, Walk, Signal, Work
- In-game view: isometric/top-down

## Naming rule

The spoken/TTS name for either child character is always **Little Engineer / مهندس کوچولو**.
The real child name is collected at the start of the game and is used only in written UI/text.

## Consistency rule

The girl and boy must use the same:
- PPE palette
- helmet treatment
- MAPNA emblem treatment
- material/lighting language
- character-sheet structure
- in-game scale logic

Do not alter the approved face, proportions, or core silhouette when producing derivative assets.
