# Game Design

**Status:** Draft / Active Design

## Current Direction
- 2D Construction Adventure
- Gas Power Plant construction journey
- Top-Down main project view
- Mini Games
- Light Simulation
- Short Sessions
- Visible Power Plant Progress
- Stars + Badges
- Next-Level Teasers
- HSE embedded across all levels
- Persian Voice-over + Minimal Text + Visual Guidance
- Offline local progression

## Core Loop
**Mission → Safety Check → Challenge → Success → Visible Construction Progress → Reward → Next Mission**

## Player Character
- کودک
- انتخاب دختر یا پسر در شروع بازی
- «مهندس کوچک» فعلاً Placeholder

## Progression
- 10 مرحله خطی
- باز شدن مرحله بعد پس از موفقیت
- Replay مراحل قبلی
- Locked بودن مراحل آینده
- Auto Save محلی
- ذخیره Stars و Badges

## HSE Design
HSE باید در تمام مراحل حضور داشته باشد، نه فقط یک Level.

نمونه مکانیک‌ها:
- انتخاب PPE
- تشخیص رفتار ناایمن
- رعایت محدوده ایمن
- انتخاب روش درست انجام کار
- توجه ساده به محیط زیست

## Guidance
**Hybrid Voice-over + Minimal Text + Visual Guidance**

## Rewards
- Primary: تکمیل بصری نیروگاه
- Secondary: Stars + Badges + Teaser
- Final: Digital Certificate + Completion Code

## Parent Job Connection
- Gameplay برای همه یکسان
- شخصی‌سازی محدود به پیام‌ها، Badgeها و توضیحات کوتاه
- روش دقیق اجرا هنوز باز است
