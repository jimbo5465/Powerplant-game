# Level Design

**Status:** Next design focus

## Global Level Rules
- نوع نیروگاه: نیروگاه گازی
- گروه سنی: 8 تا 12 سال
- نمای اصلی: Top-Down 2D
- هر مرحله یک Main Mechanic
- مراحل کوتاه و مستقل
- هر مرحله باید تغییر بصری ماندگار در سایت ایجاد کند
- HSE در تمام مراحل حضور دارد
- راهنما: Voice-over کوتاه فارسی + متن کم + Visual Guidance
- Gameplay اصلی برای همه کودکان یکسان می‌ماند

## Level Template
برای هر مرحله موارد زیر باید مشخص شوند:
- Story Context
- Construction Phase
- Learning Objective
- HSE Objective
- Mission
- Gameplay Mechanic
- Player Interaction
- Voice-over / Guidance
- Win Condition
- Retry / Fail Condition
- Stars / Badge Logic
- Reward
- Next-Level Teaser
- Visual Changes to Site
- Parent Job Connection
- Required Assets
- Development Complexity
- Reusable Components
- Open Questions

## Planned Stages — Draft
1. Site Entry, Safety & Preparation
2. Excavation & Foundation
3. Steel Structure
4. Main Equipment Delivery & Installation
5. Auxiliary Systems
6. Piping, Cabling & Connections
7. Gas Turbine & Generator Installation
8. Testing & Pre-Commissioning
9. Commissioning & Grid Connection
10. Final Power-Up / From Ground to Light

این فهرست هنوز Draft است و در مرحله بعد باید مرحله‌به‌مرحله طراحی و اعتبارسنجی شود.
